# Poster layout -- 48 x 36 in landscape, 4 columns, 15 panels

GENERATED by `figures/make_poster_layout.py`. Every headline number is read from the panel's own `*_values.json` at build time, so this document cannot drift from the figures. Prose is editorial and lives in the generator. Re-run it after regenerating any panel.

**Checkpoints: the DEPLOYED models** (`results/loto/*_mm1_holdout_Hepatocytes`), not the final-recipe retrains, which are a separate open question.

## How to read the MUST STATE lines

Every panel below carries one. They are not caption garnish: most exist because the broader, more eye-catching version of the claim was measured and found false. A poster that drops them is claiming something this project has evidence against.

## Column 1. What it is, and what it was trained on

A poster reader's first two questions. Column 1 answers them before any result is shown.

| panel | folder | what it shows |
|---|---|---|
| **arch_attn** | `figures/arch_attn/` | Model architecture |
| **P3** | `figures/P3_training_data/` | Training data |
| **S-QC** | `figures/S_riboseq_qc/` | Library quality |

### arch_attn -- Model architecture

One-hot sequence + a 5-channel ORF track + RNA-seq coverage -> per-nucleotide P-site density. ~5M parameters, CPU-runnable at inference.

**MUST STATE:** The STANDALONE arm uses NO Ribo-seq at inference. Say so explicitly -- 'predicts ribosome density' is ambiguous about it and that ambiguity is the whole application.

### P3 -- Training data

7 human cell types, 69 Ribo-seq libraries; Hepatocytes (5) held out entirely. 84,472-transcript universe. 11x depth spread across training tissues.

**MUST STATE:** Hepatocytes is drawn in a different colour because it is the LOTO holdout behind every human number on the poster, not because it was trained on. Brain was dropped for low periodicity before any pack was built.

### S-QC -- Library quality

Ribo-seq library quality for all 18 dataset arms: frame-0 fraction 74.6-87.7% against a 33% no-periodicity floor.

**MUST STATE:** Establishes that the input data clears a periodicity floor, so a downstream failure is the model's and not the library's.

## Column 2. Held-out human validation

The central claim. Four held-outs that fail in DIFFERENT ways, which is the point: same-study-withheld, cross-study, cross-lab cell line, and primary engineered cells.

| panel | folder | what it shows |

| **A1** | `figures/A1_localization_ceiling/` | Translation localization vs the ceiling |
| **A2** | `figures/A2_ribocode_dropin/` | Drop-in ORF calling |

### P5 -- Four-arm held-out human -- THE core panel

4 independent human held-outs. Standalone F1 0.831-0.911. Annotated-CDS recall 0.99-1.00; NON-CANONICAL recall 0.52-0.59.

**MUST STATE:** Panel B is the honest half and must not be cropped. Overall F1 is dominated by annotated CDS, so a single number reads ~0.9 everywhere and hides the real behaviour. Both calling arms are always reported.

### A1 -- Translation localization vs the ceiling

Predicted localization BEATS the observed Ribo-seq periodicity ceiling on all-ORFs.

**MUST STATE:** On NON-CANONICAL ORFs it reaches 94-96% of the ceiling but does NOT beat it. The caption must say both -- the all-ORF number alone overstates it.

### A2 -- Drop-in ORF calling

The predicted profile dropped into RiboCode reproduces that dataset's own ORF calls, no Ribo-seq for the query.

**MUST STATE:** State n_ref and the transcript space. A precision computed against an unstated transcript space is not interpretable.

## Column 3. Mouse cross-study: does it transfer, and where does it fail?

Three independent mouse-liver Ribo-seq experiments on one pipeline and one universe, so a difference is between EXPERIMENTS and not between code paths. This column is where the poster is honest about failure modes.

|---|---|---|
| **E1** | `figures/E1_rna_provenance/` | RNA-seq provenance |
| **E2** | `figures/E2_class_ceiling/` | Per-class ceiling |
| **E3** | `figures/E3_shallow_experiment_win/` | Predicted beats measured, below a depth |
| **P9** | `figures/P9_upset_mouse3x3/` | Where the disagreement lives -- and how much is real |

### E1 -- RNA-seq provenance

Matched vs mismatched RNA input across the 3x3 factorial.

**MUST STATE:** Reads from results/mouse_liver_3x3_canon/scored -- the CANONICAL alignment. Do not compare these to any previously reported non-canonical number.

### E2 -- Per-class ceiling

Model vs the experiment-vs-experiment CEILING, per ORF class (attn only). Annotated CDS 0.978 against a ceiling of 0.991-0.995; lncRNA 0.344 against 0.680-0.785. attn alone: annotated 0.978, lncRNA 0.344.

**MUST STATE:** The ceiling is experiment-vs-experiment agreement, not 1.0. Scoring the model against 1.0 on non-canonical classes charges it for irreproducibility in the reference.

### E3 -- Predicted beats measured, below a depth

The predicted profile calls ORFs better than the measured Ribo-seq below ~29M P-sites.

**MUST STATE:** This is the 'why not just do Ribo-seq' answer, and it is depth-conditional. State the crossover, not just the win.

### P9 -- Where the disagreement lives -- and how much is real

1,942 ORFs called by the model and NO experiment. A 28-library merged reference corroborates 7.7% of them, against a 74.5% control and a 99.3% anchor -> ~92% are FALSE POSITIVES. Both models agreeing does not rescue them (8.7%).

**MUST STATE:** The 'model only' bar is a MEASUREMENT now, not a guess, and the control must travel with it: a genuinely real singly-observed ORF corroborates 74.5% of the time, so '8% corroborated' is only interpretable beside it. NEVER present cross-architecture agreement as a confidence filter -- it was tested and it is not one.

## Column 4. Proteogenomics: what a better ORF database is worth

The application. Mouse macrophages and human HLA-I, searched with model-selected ORF databases against naive enumeration.

| panel | folder | what it shows |
|---|---|---|
| **P11** | `figures/P11_bmdm_proteomics/` | Mouse macrophages, 12 populations |
| **P12** | `figures/P12_macrophage_xsubtype/` | Predicted database vs a REAL Ribo-seq one |
| **P13** | `figures/P13_macrophage_psm_venn/` | Do the two databases find the SAME spectra? |
| **F2b** | `figures/F2b_discovery_forest/` | Human HLA-I, 4 datasets x 2 models x 2 arms |
| **D12** | `figures/D12_cpat_cpc2/` | Against the honest competitor, HLA-I only |

### P11 -- Mouse macrophages, 12 populations

12 mouse macrophage populations. Database 78x smaller and 43x denser than a naive AUG null. On TOTAL unique peptides the model is above the GENCODE-only baseline in 6/12 (median +3); the null in 0/12 (median -1,130).

**MUST STATE:** The claim is COST-NEUTRALITY, not a gain. The model is above the GENCODE-only baseline in 6 of 12 populations. An earlier BMDM-only version of this panel claimed the model was 'the only one that increases total unique peptides'; BMDM is the best of the 12 and that claim does NOT generalise. Do not print it.

### P12 -- Predicted database vs a REAL Ribo-seq one

12 populations x 3 databases, 18 mzML each. On the 11 TRANSFER populations (BMDM excluded -- the Ribo-seq databases came from it) a FIXED 506-sequence real-Ribo-seq database gives 26 novel peptides vs the model's 24, +18 vs -3 on TOTAL unique peptides (8/11 vs 5/11 above baseline), at 2.4x the discovery density.

**MUST STATE:** This is the panel that says what the model is NOT. On the 11 transfer populations a FIXED 506-sequence database built from BMDM Ribo-seq matches the per-population predicted database on yield and is ~2.4x denser. Never caption this as the model beating Ribo-seq. The claim is that it does not REQUIRE Ribo-seq -- cost and applicability, not accuracy. BMDM is the Ribo-seq arms' home ground and is excluded from every median.

### P13 -- Do the two databases find the SAME spectra?

Novel PSMs, 11 transfer populations: model 866, real Ribo-seq 1,065, shared only 386 (25% of the union). 479 model-only vs 678 Ribo-seq-only PSMs -- the two databases are COMPLEMENTARY, not redundant.

**MUST STATE:** Pair with P12, never alone. P12 says the predicted database does not out-yield Ribo-seq; P13 says it finds DIFFERENT spectra, which is what makes it worth running at all. A scan counts as shared only when both arms assigned the SAME peptide; same-scan-different-peptide totals 1 across all 12 populations, so the disagreement is about which spectra clear FDR, not about peptide assignment. Each arm has its own FDR cut, so part of the non-overlap is a threshold effect -- say so.

### F2b -- Human HLA-I, 4 datasets x 2 models x 2 arms

16 points (5 datasets x 2 models x 2 arms), ALL above 1.0; median 93.6x, range 11-2744x. On TOTAL unique peptides the Poisson arm is positive in 8/8.

**MUST STATE:** Panel (a) is a RATE RATIO; panel (b) is the absolute total and must be shown beside it. HLA-I IMMUNOPEPTIDOMES ONLY since A549 was removed 2026-08-15 -- do not call this a whole-proteome result. The Poisson arm is now positive in 8/8 because the only two failures were the A549 points (attn -35, mamba4 +11). A clean 8/8 is LESS informative than the old 9/10, not more: the dataset where the arms disagreed is gone.

### D12 -- Against the honest competitor, HLA-I only

Against CPAT / CPC2, the standard sequence-only selectors, on 3 HLA-I immunopeptidomes. The model wins on this substrate. On TOTAL unique peptides the mamba4 Poisson arm is positive in 3/3. HLA-I ONLY -- the tryptic comparison, which the model lost, was removed with A549.

**MUST STATE:** CPAT/CPC2 are the comparison a reviewer asks for; 'better than enumerating every ORF' is not a strong claim on its own. THE ASSAY SPLIT IS GONE: this used to show CPAT/CPC2 winning the tryptic proteome and the model winning HLA-I, and the tryptic half (A549) was removed. Caption it as an HLA-I result, never as 'the model beats CPAT/CPC2'. On HLA-I the model's edge depends on sub-30-aa ORFs -- 27-33% of its discoveries there come only from short ORFs, versus 0% for CPAT/CPC2.

## Numbers deliberately NOT on the poster

- Any non-canonical F1 measured before the final-recipe alignment redo. The earlier reference contained ~22% more novel calls than the corrected pipeline produces, so those values were inflated and are not comparable to anything here.
- P11's BMDM-only proteomics numbers (154x / 227x / 95x with '+31 total peptides'). Superseded by the 12-population panel.
- Cross-architecture agreement as evidence for an ORF call. Measured at 8.7% corroboration, indistinguishable from a single model.
- Any ORF-call precision without its transcript space and n_ref stated.
- "The predicted database beats Ribo-seq." It does not, on the 11 macrophage transfer populations (P12). The claim is that it does not REQUIRE Ribo-seq.
